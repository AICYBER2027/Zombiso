# Edit styles (Cinematic, Funny/Viral, Clean Professional)

Status: **first working prototype, 2026-11-17.** Tested on an original synthetic test clip (no third-party
footage). It still needs to be judged on real GTA gameplay before it becomes the default.

## 2. How the styles work (`src/vicepulse/styles.py`)

1. **Analyse once per clip** (about 5 s for a 32 s clip): loudness spikes against the clip's own normal level,
   scene changes, reaction words in the clip's *real* speech (never in the script), and where the motion is
   second by second (for a smooth moving 9:16 crop, pan speed limited).
2. **Plan per style.** The payoff is the strongest real loud moment (helped by a spoken reaction right after it).
   Story: optional teaser of the payoff → context before it (8–12 s) → payoff → natural end (after the last
   thing that happens, never in the middle of a sentence). Every effect stores the event that caused it, e.g.
   `zoom 9.2s: punch-in on loud: +11 dB over the clip's normal level`. No payoff → no payoff effects.
3. **Render in one FFmpeg run**: each story part is read from the file separately (an earlier version split one
   input, which held over 1 GB of frames in memory). NVENC when available, CPU otherwise.
4. **Quality check** on the result: size, length, audio present and near -14 LUFS, no long black screen.

| | Cinematic | Funny/Viral | Clean Professional |
|---|---|---|---|
| Story | 1.6 s teaser, fade through black, 12 s context | 1.2 s teaser, white flash cut, 8 s context | in order, 12 s context |
| Payoff | half-speed slow motion (only if strong, nobody speaking, no voice-over) + slow push-in + low impact sound | punch-in zooms on each strong loud moment / reaction (max 5, 1.5 s apart), shake, flash, impact sound | subtle 4 % push |
| Look | warm contrast grade, vignette | punchier saturation | almost untouched |
| Captions | fade in/out, serif titles | big uppercase, word-by-word highlight, reaction words in red | boxed captions, creator/brand tag |
| End | 0.6 s fade | hard end | 0.4 s fade |

All: 9:16, crop that follows the action or the whole frame on a blurred fill (chosen from how wide the action is;
Clean prefers the whole frame), platform caption safe zones, sound effects generated by FFmpeg (no sample
licences), loudness -14 LUFS, optional outro line from `config/channels.json` `brand`, optional facecam:
`--facecam x,y,w,h` (fractions of the source frame) as picture-in-picture (top right) or `:split` (camera on top,
gameplay below). The facecam's original corner is painted over so it is not shown twice. Titles move below it.

With a recorded voice-over the clip stays whole and in order (no teaser, no slow motion), so the voice stays in sync.

## 3. Settings

| Setting | Default | Meaning |
|---|---|---|
| `VICEPULSE_EDIT_STYLE` | `classic` | Normal pipeline: `classic` (original template), `cinematic`, `viral`, `clean` |
| `VICEPULSE_LIVE_EDIT_STYLE` | empty (= above) | Live clips (Twitch and direct feeds) |
| `vicepulse render --style …` | | One run with a style |
| `channels.json` → `brand` | handle, colour, outro | Per-channel branding used by the styles |

Compare styles on one highlight:

```
vicepulse style-compare --clip 12                                 # a scripted clip from licensed footage
vicepulse style-compare --file my_recording.mp4 --own-test-footage --start 40 --end 75 \
    --channel en --facecam 0.02,0.63,0.235,0.335:pip              # your own recording
```

It writes `cinematic.mp4`, `viral.mp4`, `clean.mp4` and `side_by_side.mp4` and prints every plan with its reasons,
timings and quality checks.

**Dependencies:** none new. FFmpeg (already in the worker image; filters used: ebur128, scene select, delogo,
boxblur, eq, lutyuv, vignette, ass, loudnorm, anoisesrc, sine) and the DejaVu fonts already installed.

## 4. Test results (laptop: i5-7300HQ, GTX 1050, 8 GB; 720x1280 unless noted)

Original 32 s test clip (1280x720 60 fps): moving shapes, scene change at 12 s, explosion + loud boom at 20 s,
a smaller one at 25.5 s, fake facecam corner.

| Run | Cinematic | Funny/Viral | Clean |
|---|---|---|---|
| Output length | 21.7 s | 17.3 s | 20.1 s |
| Render, NVENC, crop + facecam | 15.3 s | 13.5 s | 8.8 s |
| Render, CPU only (libx264) | 17.1 s | 12.0 s | 9.8 s |
| Render, 1080x1920 NVENC | 24.6 s | | |
| Quality check | pass (-13.9 LUFS) | pass (-13.8) | pass (-13.4) |

- Analysis: about 5 s per clip, shared by all styles and platforms.
- Peak memory for the whole three-style run, including the side-by-side preview: **about 500 MB** (720p),
  **about 700 MB** (1080p). Before the per-segment fix: >1 GB and 2–4× slower.
- Filter work dominates at 720p, so the CPU encoder is about as fast as NVENC there. NVENC still frees CPU for
  the other streams.
- Automated tests: `tests/test_styles.py` (10 tests). They cover plans, caption sync, branding, a real
  three-style render and a live edit in the Viral style.
